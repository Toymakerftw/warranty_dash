CSV Format Instructions

Required Columns

  • asset_tag - Unique identifier
  • manufacturer - Device manufacturer
  • service_tag - Serial number
  • warranty_end_date - YYYY-MM-DD format

Optional Columns

  • model - Device model
  • purchase_date - YYYY-MM-DD format
  • notes - Additional information

Upload Mode Details

Add New Assets
Only imports assets that don't already exist (based on asset_tag). Skips existing assets.
Update Existing
Updates existing assets (based on asset_tag). Skips assets that don't exist.
Full Sync
Deletes all existing assets and replaces with CSV data. Use with caution!
